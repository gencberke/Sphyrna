01

The six rules, v4

Ink v4 takes Orca's quiet system and keeps what makes Sphyrna recognisable. The switches above this chapter (Q1–Q6) redraw every window below both ways, the default first; the v3/v4 switch in the bar changes the tokens under every chapter. Nothing here is approved yet: this page is the proposal.

01

Two planes

The sidebar is a plane one step lighter than the content. The content is the canvas. Hairlines divide; nothing is boxed twice; only what you act on is lifted.

02

Two voices

SF Pro for what you read, labels included. SF Mono only for what the machine says: branches, paths, model ids, times, tokens, counts, keys.

03

Colour means state

The chrome is neutral grey; the default action is a neutral fill. Periwinkle marks focus and what is current. Orange, blue and red are status; green is content only. A project's tone is its mark and its tab.

04

One control family

Four heights (24, 28, 32, 36), one radius (8), one hover, one focus ring, six button roles. A control looks the same wherever it appears.

05

Three reading points

The sidebar says how every session is doing. The header says how this one is doing and what you can do with it. The status bar says how the accounts are doing.

06

Quiet by default

Feedback matches the duration, the way back is never coloured, a tooltip only names, and copy never claims more than the state proves.

Six roles at four heights, one radius, one hover and one focus ring. Filled means Return: the one filled button is the one Return presses. A back-out path (Cancel, Dismiss, Close, Discard) is ghost or secondary, never coloured, and carries no key chip.
