Composer new

Where chat earns its keep: everything you can send Claude Code from the terminal, with less typing and nothing lost. Here you come back to a four-day-old session.

Why revoke the whole family on reuse instead of only the reused token?

A reused refresh token means two parties hold it: the real client and whoever copied it. The server cannot tell which one is honest, so revoking only that token leaves the other copy's next token alive.

Revoking the family logs both out and forces a fresh sign-in. That is the usual defence when refresh tokens rotate.

Terminal mode today's Loom
