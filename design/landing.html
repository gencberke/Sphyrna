Sphyrna

Run your Claude Code sessions side by side, in one window on your Mac.

Every session sits in one sidebar with its live state. Open one on the terminal, as Claude Code draws it, with its state around it. Sphyrna starts each session, resumes it later, and stops what it started when you quit.

For macOS 27Made for Claude CodeInk and Paper

Made for running many sessions at once.

Sphyrna is a native Mac app for one person who runs many Claude Code sessions side by side. It starts each session in its own process, works from what Claude Code keeps on your Mac, and needs no account of its own.
