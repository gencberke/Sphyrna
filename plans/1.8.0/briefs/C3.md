# C3: Settings → Connections and Home's connect cards in v4

**Goal.** Connections shows all five harnesses from the catalogue in v4's look. A missing CLI shows "Not found on this Mac"
with how to install it, and its switch is off and disabled. A found harness can be switched on. Home's first-run "Connect your
agents" follows the same states. This is FEEDBACK-6 FB6-13 step 3 and the user's own words: off but visible, and "sistemde
bulunamıyor".

**Starts after** B1 (v4 controls) and C1 (the catalogue).

**Read.**
- DESIGN §6 Connections (today's rows, detail card and headlines) and the v4 Connections window in `reference.html`.
- In `v2`, `Sources/LoomCatalogUI/`: `SettingsConnectionsView.swift`, `SettingsConnectionsContent.swift`,
  `SettingsConnectionsModel.swift`, `SettingsConnectionsSetup.swift`, `CatalogModel+Connections.swift`, `HomeConnect.swift`.
- C1's `HarnessDescriptor` and `HarnessAvailability`.
- For the states: T3 Code `apps/web/src/components/chat/ModelPickerSidebar.tsx:16-23` (Unavailable, Limited, Not ready) and
  `packages/provider-grok/src/server/status.ts` (the not-installed message).

**Write set.** The Connections files above, `HomeConnect.swift` (view), `LoomTheme+Settings.swift`'s Connections tokens, the
harness mark assets for opencode, agy and pi (`assets/harness/`), their tests, and DESIGN §6's Connections lines.

**Approach.**
1. **One row per harness in `HarnessCatalogue.all`:**
   - the mark, the name and the version (mono), then the status dot, the headline and the switch;
   - the headlines are DESIGN's, plus "Not found on this Mac" and "Off" (the user switched it off);
   - a Not found row's switch is off and disabled;
   - an Off row is dimmed except its switch.
2. **The detail card for a Not found harness:**
   - "Not found on this Mac. Sphyrna looks for `<command>` on your shell's PATH.";
   - the install command with Copy and Open Terminal (as today's setup block);
   - the docs link;
   - Check Again, which re-reads PATH.
3. **Marks for opencode, agy and pi:** each is a template image like Codex's knot, drawn from the vendor's public mark at
   12–14 pt. If a vendor mark cannot be used, draw a neutral two-letter mark and say so in the report; `@user` decides.
4. **Home's connect cards:**
   - Claude and Codex always; the others only when found;
   - each in its state, with its one action (Copy Install Command, Copy Sign-In Command, or Turn On).
5. **Look:** v4 controls only (switch, outline and ghost buttons, badges). No layout outside these two surfaces changes.

**Done when.**
- With a fake PATH that lacks `opencode` and `pi`, Connections shows Claude, Codex and agy as found, and opencode and pi as
  "Not found on this Mac" with disabled switches.
- Switching agy on persists, and C2's lists pick it up.
- Screenshots in Ink and Paper are in `evidence/r9/c3/`.

**Checks.** The Connections and Home connect suites (find them with
`grep -l "SettingsConnections\|HomeConnect" Tests/LoomCatalogUITests/*.swift`) and new tests for the Not found row and the
switch; then `--tests`.
