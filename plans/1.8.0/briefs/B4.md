# B4: the model and effort panel

**Goal.** The model chip opens one floating panel over the window, in this order:
- a harness rail on the left, then the models with search;
- then, on the same surface, the chosen model's own effort levels;
- ↵, ↵ and done.

It replaces the 332 pt popover (`ComposerModelPopover`). This is FEEDBACK-6 FB6-7 and FB6-8, option B (D-103 Q7).

**Starts after** B1 and C4.

tests; DESIGN §11's panel lines.

**Approach.**
1. **Presentation:** a 640 × 440 panel at elevation 3 over the scrim, in the palette's overlay layer, opened from a chip. It
   is keyboard-first: focus starts in the search field.
2. **The rail:**
   - Recent (the last five choices across harnesses);
   - each catalogue harness: mark, name, model count, and a state word when not ready;
   - dimmed rows for Off and Not found, with "Connect…" opening Settings → Connections;
   - ↑ ↓ move within the list, ⇥ moves between the rail and the list.
3. **The list:**
   - one 32 pt row per model: full name, a description line, the context size in mono;
   - the current model marked with the accent;
   - typing filters across all harnesses, grouped by harness.
4. **The effort step:**
   - ↵ on a model with `efforts` replaces the list with that model's levels, under a back row naming the model; the default
     level is marked, and the current one is selected;
   - ↵ confirms and closes; a model without efforts closes at once;
   - ⌫ or ← goes back; Esc closes without a change at any step.
5. **Applying:** confirming writes `HarnessLaunchChoices` through C4's rules (a cross-harness pick switches the draft's
   harness). In a running session's header, the panel shows the session's harness only, and applies as today: the next session
   or the CLI's own `/model`. Write which in the report.
6. **The chip** reads `[mark] <model> · <Effort>`.
7. **Accessibility:** the panel is a dialog; the rail and the list are lists; the effort step announces "Effort for <model>".

**Done when.**
- From the draft, a user can pick a Codex model and its effort with the keyboard alone (chip, type, ↵, ↵), and the draft
  switches to Codex.
- Esc anywhere leaves the choice unchanged. Off and Not found harnesses cannot be chosen and offer Connect.
- `ComposerModelPopover` is gone, or kept only by the frozen Chat code; say which.
- Screenshots in `evidence/r9/b4/`.

**Checks.** New `ModelPanelTests`: the filter across harnesses, the effort step, Esc and ⌫, the disabled rows, the
