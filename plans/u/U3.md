# U3 — conversation tab state (non-UI)

Stage [U](../STAGE-U.md) · wave 2 · protocol: [RUN-1](../RUN-1.md#protocol-for-every-implementer-slice). Depends on F1 (same files).

## Goal

The model behind conversation tabs (D-33), so the strip (U4) is a thin view: a few pinned conversations plus the current selection, persisted, kept consistent with selection, run ownership moves and deletion.

## Model (DP-U1 default)

- `openTabs: [UUID]` pinned, ordered, persisted in `UIPreferences` (tolerant decode, de-duplicated, cap 8).
- Visible tabs = pinned + the selected conversation as one transient tab when it is not pinned; selecting another sidebar row replaces the transient tab.
- Pin: explicit "Open in Tab" (context menu item and double-click on a card — the UI part is U4; the model API is here) and automatically when Loom starts or resumes a conversation (`ConversationController.swift:~164,169,192`).
- Over the cap: evict the oldest pinned tab that is not live and not in an attention state; if none, refuse to pin with a reason.
- Close: unpins; never stops a run (the terminal stays in `ConversationController.entries`); closing the selected tab selects the right neighbor, else the left, else nothing.
- `/clear`, `/new`: when `reconcile` moves a terminal to a new card (`ConversationController.swift:~285-292`), a pinned old owner is replaced in place by the new card.
- Missing IDs (deleted or unreadable rows) are dropped at load and on `ensureRow` failure; `forget(sessionID:)` for CP4.
- Row retention: tab IDs join the `pruneRowModels` keep set (`CatalogModel.swift:~390-400`); `start()` ensures rows for tab IDs (≤ 8 point lookups); titles and indicators come from `SessionRowModel`.
- Selecting a tab only shows the conversation; it never starts a provider, PTY or terminal (contract §10).
- Debounce the preference write on rapid switching (today each `select` writes `ui-preferences.json` synchronously).

## Scope

Write: `Sources/LoomCatalogUI/UIPreferences.swift`, new `Sources/LoomCatalogUI/ConversationTabs.swift`, `CatalogModel.swift` (keep set, ensure rows, ownership of the tabs object, select integration, debounce), `ConversationController.swift` (pin on start/resume, ownership-move replace), tests `Tests/LoomCatalogUITests/ConversationTabsTests.swift` and additions to `DisplayAndPreferencesTests`, `CatalogModelTests`, `ConversationControllerTests`. Out of scope: any view, menus, evidence (U4).

## Done when

All model rules above have unit tests (persist/restore, cap and eviction, de-dupe, transient replacement, close-neighbor, ownership move, missing ids, forget, no terminal created on tab select, debounce). Existing suites green.
