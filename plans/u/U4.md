# U4 — conversation tab strip, shortcuts and evidence

Stage [U](../STAGE-U.md) · wave 4 · protocol: [RUN-1](../RUN-1.md#protocol-for-every-implementer-slice). Depends on U3, I1, UD, F5 (signposts).

## Goal

A refined, light tab strip above the terminal for quick switching between a few threads (D-33), with keyboard support and evidence.

## Context

- `DetailView.body` = VStack(`DetailHeader` 36 + 16 pt, `Banners`, `DetailContent`) (`DetailView.swift:~11-15`); the header hit-test sweep (`AppDelegate.swift:~895-936`, evidence) assumes the header geometry — the strip goes between `Banners` and `DetailContent`, inside the panel; hidden with fewer than two visible tabs.
- Terminal swap: `DetailContent` shows `TerminalHost(panel:).id(ObjectIdentifier(terminal))` (`:~163-167`); terminals are kept alive per live run.
- Shortcuts (DP-U2 default): Next/Previous tab Shift+Cmd+] / Shift+Cmd+[ and Ctrl+Tab / Ctrl+Shift+Tab; Close Tab Opt+Cmd+W (Cmd+W keeps closing the window); "Open in Tab" in the card context menu and the conversation actions menu, double-click on a card pins. Taken today: Cmd+, H Q O N Shift+N R . W M 1 2, Ctrl+Cmd+S, Opt+Cmd+N (evidence builds). Menu key equivalents win over the terminal's `keyDown`.
- Evidence (new file under `Sources/loom-app/Evidence/`, one dispatch line): `tab-pin:<id>`, `tab-unpin:<id>`, `tab-select:<id|next|prev>`, `tab-close:<id>`; snapshot `tabs{ids, pinned, selected, transient}` and `preferences.openTabs`. Regression scenario from CP5: no stale row after switching during a stream and after Cmd+W / reopen.

## Scope

Write: new `Sources/LoomCatalogUI/ConversationTabStrip.swift`, mount line in `DetailView.swift`, context-menu item in `SidebarView.swift` (card menu) and `DetailView.swift` (actions menu), `AppDelegate.installMenus` (Window or View menu items), evidence file + dispatch line, tests (strip visibility rules, keyboard command routing on the model), `design/UI-MAP.md` (new surface + shortcuts). Out of scope: tab model rules (U3), Settings, footer.

## Done when

- Strip matches the UD design at 1220 and 780 pt widths with 2, 5 and 8 tabs (overflow rule), indicators live, rename reflected, close on hover, transient styling.
- Shortcuts and menu items work (evidence commands + menu validation tests).
- Switch latency (signpost: tab select → terminal view attached) measured for 1, 5 and 8 live fake terminals during heavy output; recorded beside sidebar-selection latency; no stale row in the CP5 scenario.
- Screenshots captured.

## Checks

`swift build`; `LoomCatalogUITests`; theme guard; evidence run on a `run1-U4` package; `git diff --check`.
