# I3 — motion and accessibility pass

Stage [I](../STAGE-I.md) · wave 4 · protocol: [RUN-1](../RUN-1.md#protocol-for-every-implementer-slice). Depends on I2; serialized after U4 for `AppDelegate.installMenus`.

## Goal

Close the accessibility gaps that need no design-rule change and add A's short transitions without harming the terminal.

## Context ([I scan §3–§4](../experiments/run1-planning-scans/I-identity.md))

- No transitions exist. A: selection fill 120 ms, banner/request 200 ms, ease-out, instant or cross-fade under Reduce Motion; nothing animates inside the terminal panel; `Banners`/`RequestList` sit above `TerminalHost` in a VStack (`DetailView.swift:~164-166`) → opacity-only.
- `ProjectHeader` collapses only via `onTapGesture` (`SidebarView.swift:~273`): not keyboard or VoiceOver operable. No `.isHeader` on day headings (`:~170`), `SectionTitle`, `ProjectHeader`; chevron has no expanded/collapsed value; `Message` image not hidden; `Message`/`Notice` not grouped.
- No focus-search shortcut and no Esc-to-clear; Cmd+F is free (the app never sends Cmd keys to the terminal). Project menu hit area 22×20 → at least 24×24 via content shape without visual change.
- Increase Contrast: none. Raise hairline to ~0.30 white, lift `text.secondary`, thicken the focus ring when `colorSchemeContrast == .increased`.
- Risk to check first: Approve and Resume carry `.keyboardShortcut(.defaultAction)` (`DetailView.swift:~274,~320`). With a live terminal focused and an approval card visible, Return may trigger Approve instead of reaching the CLI. Reproduce with the fake provider (approval card + `type:<id>:` evidence or a key event); if real, scope the default action so Return reaches a focused terminal, with a regression test.

## Scope

Write: `SidebarView.swift`, `DetailView.swift`, `LoomTheme.swift` (contrast-aware tokens, motion tokens), `CatalogModel.swift` (search focus request), `AppDelegate.swift` (Edit or View menu: Find Cmd+F), tests. Out of scope: DP-I1 diamond, new surfaces, Settings.

## Done when

- Keyboard: Cmd+F focuses search, Esc clears it; Tab reaches project headers (Space/Return toggles), cards and menus under Full Keyboard Access.
- VoiceOver: header traits, expanded/collapsed value, grouped notices (verified by accessibility tree inspection in a test or an evidence dump).
- Motion gated by Reduce Motion (test toggling the environment value), opacity-only above the terminal, chase unchanged (D-12).
- Increase Contrast token resolution unit-tested.
- Return/default-action finding resolved or shown not to occur, with evidence.

## Checks

`swift build`; `LoomCatalogUITests`; theme guard; evidence screenshots and snapshot; `git diff --check`.
