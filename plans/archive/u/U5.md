# U5 — daily-use polish

Stage [U](../STAGE-U.md) · wave 4 · protocol: [RUN-1](../RUN-1.md#protocol-for-every-implementer-slice). Depends on F5 (`CatalogModel` observation changes), U3.

## Goal

Three small fixes found in planning that the user would notice in daily use.

## Items ([architecture scan](../experiments/run1-planning-scans/arch-scale.md) §1.3, §3.4, §6)

1. **Relative times and day headings never tick.** `now` changes only on reload and window activation (`CatalogModel.swift:~352,~471`); "5m" stays "5m", "Today" is wrong after midnight. Add a minute-aligned tick of `now` only while the window is active and visible (no timer when hidden or inactive; cancel on deactivation), and a day-change refresh at local midnight while active.
2. **Window frame not persisted.** `window.center()` + fixed 1220×780 (`AppDelegate.swift:~179-183`). Use `setFrameAutosaveName` (per bundle identity) so size and position persist; first launch keeps 1220×780 centered; minimum 780×500 unchanged.
3. **First start shows nothing while the toolchain resolves.** The login-shell environment capture and `claude --version/--help` run on the first New/Resume (`SessionRuntime.swift:~585-594`, `LaunchEnvironment.swift:~122`, 30 s timeout); for Claude the card appears only after launch returns and "Starting…" never shows. Show a visible "Preparing Claude…" busy state on the requesting surface until the launch returns or fails (no prefetch — prefetching the environment at launch is a policy change and stays out).

## Scope

Write: `CatalogModel.swift`, `SessionDisplay.swift` (if the relative-time formatter needs it), `SidebarView.swift` (only if needed), `AppDelegate.swift` (`makeWindow` only), `ConversationController.swift` (busy state), tests. Out of scope: toolchain prefetch, terminal snapshot after run end.

## Done when

Unit tests: tick runs only while active (inject a clock/scheduler), midnight rollover regroups, frame autosave name set per identity, busy state visible during a delayed toolchain (`--fake-toolchain-delay` in evidence). Indicator/idle cells unchanged (no wakeups while inactive).
