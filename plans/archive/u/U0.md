# U0 — Claude usage index (non-UI)

Stage [U](../STAGE-U.md) · wave 1 · protocol: [RUN-1](../RUN-1.md#protocol-for-every-implementer-slice).

## Goal

A `LoomCore` component that turns what Claude Code already writes locally into usage aggregates — incrementally, bounded, deduplicated — with an estimated cost from a static price table. No new processes, no network, no polling. Provider-generic records (Claude only today).

## Facts (from [the usage scan](../experiments/run1-planning-scans/U-usage-data.md); verify field names against fixtures you build, never against the real `~/.claude`)

- Transcripts: `<config>/projects/<encoded cwd>/<sessionId>.jsonl`, plus subagent files `projects/<p>/<sessionId>/subagents/agent-<id>.jsonl` (scan `projects/**` recursively; skip `memory/`, `tool-results/`). Usage only on `"type":"assistant"` lines: line `timestamp` (ISO-8601 ms Z), `requestId`, `sessionId`, `isSidechain`, `isApiErrorMessage`; `message.id`, `message.model`, `message.usage` {`input_tokens`, `output_tokens`, `cache_creation_input_tokens`, `cache_read_input_tokens`, `cache_creation.{ephemeral_5m_input_tokens, ephemeral_1h_input_tokens}`, `service_tier`, `speed` ("standard"/"fast"), `inference_geo`, `server_tool_use.web_search_requests`}. No `costUSD` in current versions (legacy; accept if present). `<synthetic>` model lines carry zero tokens: skip.
- One assistant message is written once per content block with identical usage → dedupe by (`message.id`, `requestId`); keep the larger total on conflicts, prefer non-sidechain; a sidechain replay (same `message.id`, new `requestId`, `isSidechain: true`) must not double count. Cross-file duplicates (resume/copy) count once.
- Files are append-only in practice; Claude may set aside a transcript as `<id>.orphaned-<ts>-<suffix>.jsonl` or `<id>.jsonl.superseded-<ts>` — exclude those names (DP default). Claude deletes transcripts after `cleanupPeriodDays` (default 30): Loom's index keeps its history; a vanished file never reduces totals.
- Config dir resolution must mirror the launcher: `ProviderToolchain.profileDirectory` (evidence `--claude-config`), else `CLAUDE_CONFIG_DIR` from the resolved terminal environment, else `~/.claude` (`SessionRuntime.swift:~637-683`, `ProviderToolchain.swift:~5-9`). Add a pure `ClaudeProfileLayout` that encodes this (inputs passed in; it reads no environment itself); do not edit `SessionRuntime` (F4 is moving it) — list the later switch-over under Doc impact. Reuse `ClaudeRegistryReader`'s ownership stance (uid, no symlink escape) for the projects dir.
- Prices: verify against the official pricing page (platform.claude.com/docs/en/about-claude/pricing) or the `claude-api` skill's pricing reference; the planning scan's table (fetched 7 Oct 2026) is a starting point, not authority. Notable: cache multipliers differ for some models (e.g. Opus 5.5 and Fable 5.1 cache reads); fast mode and `inference_geo: "us"` (1.1×) multipliers; web search $10 / 1,000. Normalize model ids (date suffixes, aliases). Table carries an `asOf` date.

## Design

- `ClaudeUsageIndex` (actor or a class confined to its own serial queue, utility QoS): SQLite file at a given URL (`usage-index.sqlite3` in the data root; schema versioned; corrupt or newer → delete and rebuild). Tables: `file(path, dev, ino, size, mtime, offset, guard_hash)`, `msg(key INTEGER PRIMARY KEY, file_id, ts_ms, session, model, input, output, cw5, cw1, cr, web, speed, geo, sidechain)`; optional day roll-up if raw rows are pruned (raw retention default 90 days).
- Scan: stat each candidate file; unchanged → skip; grown → verify a 64-byte guard hash ending at `offset`, read only new bytes, parse whole lines up to the last `\n` (never advance past a partial tail); shrunk, new inode or guard mismatch → drop that file's rows and re-parse. Cheap byte gate (`"type":"assistant"` and `"usage"`) before JSON decoding; cap line length (~16 MiB); malformed lines skipped. Cold start reads files modified in the last 90 days only. Yields between files; cancellable.
- API: `refresh(paths: [URL]? = nil)` (nil = all; a path = tail one transcript, from the hook's `transcript_path`); `snapshot(range:now:timeZone:) -> UsageSnapshot` (totals by token type, per day, per model, sessions count, cache share, est. cost with unknown-model flags, approximate 5-hour activity window via ccusage's block rule, `asOf`, price-table date); `forget(sessionIDs:)` that removes file rows of those sessions and clears the `session` column of their message rows (DP-CP4-6 default: tokens stay, the link goes).
- `UsageSnapshot` and records are `Sendable` value types with a `provider` field.

## Scope

Write: new `Sources/LoomCore/ClaudeUsageIndex.swift` (+ `ClaudeUsageParser.swift` if useful), `Sources/LoomCore/UsagePricing.swift`, `Sources/LoomCore/ClaudeProfileLayout.swift`, `Sources/LoomCore/UsageSnapshot.swift`; tests `Tests/LoomCoreTests/ClaudeUsage*Tests.swift` with a fixture builder writing synthetic profiles under a temp dir; evidence `plans/experiments/run1-U0-usage-index.json` (value-free numbers). Out of scope: UI, `SessionRuntime`, hooks wiring (U1), any real `~/.claude` read.

## Done when

Fixture tests (each must fail against a naive implementation where meaningful): per-block duplicates; streaming partials (largest wins); partial last line then completion; append growth reads only new bytes (count bytes read); rewrite/rotation/shrink re-parse without double counting; sidechain files counted, sidechain replays dropped; cross-file duplicates once; synthetic and API-error lines ignored; unknown model → tokens, nil cost, flagged; malformed lines (invalid JSON, binary, oversized, missing fields, negative counters) skipped without crash; cache split vs legacy single field; fast + geo multipliers; day boundaries in a non-UTC zone; orphaned/superseded files excluded; `forget` behavior; index corruption → rebuild. Hand-computed cost values pinned (e.g. the Haiku 4.5 example in the scan reproduces $0.0222902). A generated ~1 GB corpus measures cold scan time and peak memory and warm refresh time (record in the evidence file; run it in the build slot).
