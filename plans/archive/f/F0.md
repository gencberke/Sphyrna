# F0 — local check command, build slot and perf comparer

Stage [F](../STAGE-F.md) · wave 1 · protocol: [RUN-1](../RUN-1.md#protocol-for-every-implementer-slice).

## Goal

One command runs the repo's required local checks (there is no CI), every build goes through one build slot, and a stage-end perf run can be judged automatically against the package I baseline.

## Context

- Today the routine is by hand (DEVELOPMENT.md §2–§3); `scripts/dev-paths.sh` has `loom_scratch_path` (refuses `~/Documents`, exit 2) and `loom_send_command`. `/usr/bin/lockf` exists (`-k` keeps the file and orders waiters, `-t N` times out with exit 75 without running the command). The run's lock file is `~/Library/Caches/loom-run1/build-slot.lock`.
- 377 `@Test` in 4 targets. Window tests (need an unlocked screen): `TerminalImageLimitTests.byteQuotaCoversRasterRounding`, `TerminalPartialDrawTests.layerBackingStorePreservesPixelsOutsideTheDirtyRect`, `SidebarStatusTests.hostedWorkingIndicatorRunsOnlyWhenTheEnvironmentAllowsIt`, `SidebarStatusTests.realSidebarRunsAWorkingRowOnlyForAnActiveWindowAndExpandedSidebar`. Verify these names in the source before using them in `--skip`.
- `git diff --check` skips untracked files. `.gitignore` has no `__pycache__` entry, so `py_compile` must use `PYTHONPYCACHEPREFIX` in a temp dir.
- The command-channel name (`local.loom.desktop.dev.command.<16 hex of sha256(realpath(dir))>`) is duplicated in `Sources/LoomLaunchOptions/LaunchOptions.swift:53`, `scripts/dev-paths.sh`, `scripts/cp5-d-measure.py:~273` and `scripts/perf/indicator_cost_lib.py:~22`. ## Scope

Write: new `scripts/with-build-slot.sh`, new `scripts/check.sh`, new `scripts/perf/compare_baseline.py`, `scripts/perf/perf_paths.py`, `scripts/cp5-d-measure.py` and `scripts/perf/indicator_cost_lib.py` (channel helper import only), `scripts/README.md`, `DEVELOPMENT.md` §1–§3 and §7 (only the lines about these commands), `.gitignore` (add `__pycache__/` if useful). Out of scope: Swift sources, the release scripts, any measurement run.

## Done when

1. `scripts/with-build-slot.sh <cmd…>` runs the command under `lockf -k -t ${LOOM_SLOT_TIMEOUT:-3600}` on `${LOOM_BUILD_LOCK:-$HOME/Library/Caches/loom-run1/build-slot.lock}`, refuses a lock path under `~/Documents` (exit 2), maps lockf's 75 to exit 3, writes a best-effort `<lock>.holder` line (pid, time, command), and returns the command's exit status.
2. `scripts/check.sh` (zsh, `set -euo pipefail`, style of `package-dev-app.sh`):
   - default: `git diff --check`, `git diff --cached --check`, a trailing-whitespace grep over untracked non-ignored files, `zsh -n` on `scripts/**/*.sh`, `py_compile` on `scripts/**/*.py`, `clang -Wall -Wextra -Werror -fsyntax-only` on the C sources with the needed include paths, then (in the slot) `swift build --scratch-path <scratch>`;
   - `--suite <Name>…` adds `swift test --filter` for those suites; `--tests` runs all test targets; window tests are skipped unless `--windows` (which requires `--idle`);
   - `--full --idle`: release build and full release suite (`swift build -c release`, `swift test -c release`); without `--idle` it exits 2 with a one-line reason. (F3 later adds the staged release-tree build to this mode; leave a clearly named hook function for it.)
   - `--scratch <path>` or `LOOM_SCRATCH_PATH`; `--macro-plugin <dylib>` optional; logs to a file outside the repo; prints a one-line verdict and the "N tests passed" line. Exit codes 0 pass, 1 fail, 2 usage/refusal, 3 slot timeout.
3. `scripts/perf/compare_baseline.py <run-dir> [--baseline <json>]` reads a matrix run, pairs reference and candidate cells when present, and exits non-zero on: stream1 total ≥ 40 % (CPU40), candidate stream1 app median > reference median + 1.5 points (or > baseline max + 1.5 without a reference), spinner1 median > baseline max + 2.5, hidden stream1 app > baseline + 1.0, latency p95 median > 25 ms, any invalid cell. Thresholds are constants at the top with a comment that they are the run's regression gates, not product budgets (O-01 is open). Prints a table. A `--self-test` mode checks it on the package I baseline JSON shape.
4. Docs: DEVELOPMENT.md §2–§3 and scripts/README.md describe the new commands; the macro-plugin note says whether the flag is needed (with the command you ran).

## Checks

`zsh -n` on the new scripts; `py_compile`; `compare_baseline.py --self-test`; run `scripts/check.sh` (default mode) and `scripts/check.sh --suite LoomLaunchOptionsTests` once each in your worktree (they take the build slot); show a deliberate failure path (e.g. a temp trailing-whitespace untracked file → exit 1, then remove it). Do not run `--full`.
