# F2 — quit coordinator off TerminalRunController

Stage [F](../STAGE-F.md) · wave 1 · protocol: [RUN-1](../RUN-1.md#protocol-for-every-implementer-slice).

## Goal

The production quit path no longer runs through `TerminalRunController` (an A-slice synthetic-terminal state machine). A small `AppShutdownCoordinator` owns the quit state machine; behavior is byte-for-byte the same.

## Context (verified in planning)

- `applicationShouldTerminate` (`Sources/loom-app/AppDelegate.swift:128-141`): before startup finishes it returns `.terminateLater`, awaits `startupTask`, replies true if `controller == nil`, else `beginQuit`; after startup with `controller == nil` → `.terminateNow`.
- `beginQuit` (`:143-152`): `conversations.quitStarted()` (sets `model.quitting`, `CatalogModel.swift:754`), status message, evidence `quitRecorder`, then `controller.requestQuit(prepareReply:reply:)`.
- `TerminalRunController.requestQuit` (`Sources/LoomTerminal/TerminalRunController.swift:~110-130`): guards running/finished, runs `shutdown()` detached, awaits `prepareReply` off the main actor, delivers with `RunLoop.main.perform(.common)` + `MainActor.assumeIsolated`, sets `.finished` / `.failed`.
- `quitFinished` (`AppDelegate.swift:560-588`): writes `shutdown.json`, replies, or shows "Try Again / Keep Loom Open" (Try Again calls `NSApp.terminate`).
- Shutdown closure built at `AppDelegate.swift:368-380` (counts attempts for `--fail-first-quit`, calls `runtime.shutdown()` or `supervisor.shutdown()`); the controller exists only when the supervisor was created (`:391`).
- Tests: `Tests/LoomTerminalTests/TerminalRunControllerTests.swift` — quit tests at lines ~81, 152, 186, 220, 289 move to the new type; synthetic-run tests (~60, ~120) stay.
- Evidence keys read by scripts: `quitState`, `quitAlert`, `terminalState`, `terminalSurfaceExists` (`AppDelegate.swift:716-721`, `:794`); `controller?.terminalFontSize` (`:83`) and `presentMainWindow`'s `controller?.surface` (`:252`) must keep working for the synthetic dev terminal.

## Scope

Write: new `Sources/LoomCore/AppShutdownCoordinator.swift` (Foundation only, `@MainActor`, its own reply enum — LoomCore imports no AppKit); `AppDelegate.swift` lines in the ranges above (quit and startup wiring only — F1 edits other lines of the same file in parallel; keep your hunks inside these ranges); `TerminalRunController.swift` (remove quit state, keep the synthetic run; rename only if trivial, otherwise keep the type name); move the quit tests to new `Tests/LoomCoreTests/AppShutdownCoordinatorTests.swift`. Out of scope: evidence separation (F3), menus, Settings.

## Done when

- Every behavior above is preserved, including the nested-run-loop delivery and the duplicate-request guard; evidence key names and values unchanged.
- `TerminalRunController` has no quit or shutdown responsibility; `docs/ARCHITECTURE.md` §3 "Quit" and the §9 hotspot line are updated (inside your write area).
- Moved tests pass against the new type; synthetic-run tests still pass.

`swift build`; `swift test --filter AppShutdownCoordinatorTests`, `--filter TerminalRunControllerTests`; `git diff --check`. The end-to-end quit evidence (`scripts/cp5-c-acceptance.sh` §3–§4) is run by the planner-reviewer on a package after the wave.
