# F6 — optimizer items and catalog robustness

Stage [F](../STAGE-F.md) · wave 2 · protocol: [RUN-1](../RUN-1.md#protocol-for-every-implementer-slice). Depends on F4 (split files).

## Goal

Close the two deferred optimizer items worth taking, and remove one total-failure mode.

## Context (verified in planning)

- **S2** — full process-table snapshot to read one PID: `Sources/LoomCore/EnvironmentResolutionJob.swift:28`, `ProcessSupervisor.swift:427-433` (scoped mode needs only the leader), `SessionRuntime.swift:~997` (Codex part, after F4 in `SessionRuntime+Codex.swift`). `ProcessTable.record(pid:)` exists (`ProcessTable.swift:~77`, tested in `ClaudeRegistryTests.swift:~293`). (`AppDelegate.swift:319` is F5's.)
- **F10** — `runOwnedJob(scope: .environment)` keeps `environmentScope` (one idle run-host process) until Quit after the first conversation start (`ProcessSupervisor.swift:299-345`). Release the scope when it has no forked members after the job finishes; keep the ownership guarantee (members verified empty before release; a later job opens a new scope).
- **Undecodable row** — `SessionCatalog.decodeSession` throws `invalidRow` (`:872-878`) for an unknown provider, lifecycle or malformed UUID; `sessionPage` and `sessions()` propagate it, so one bad row makes the list show "Conversations could not be read" and `restoreCatalogSessions` fails the runtime start (`AppDelegate.swift:~392`). Change: skip and count undecodable rows (list paging stays correct; the count is exposed for an info line and evidence), never write or delete them.

## Scope

Write: `Sources/LoomCore/ProcessSupervisor*.swift`, `EnvironmentResolutionJob.swift`, `SessionRuntime+Codex.swift` (S2 site only), `SessionCatalog*.swift` (decode path and a skipped-row counter), `Sources/LoomCatalogUI/CatalogModel.swift` only to surface the skipped count as existing info text if trivial (else list it under Doc impact/Needs), tests in `Tests/LoomCoreTests`. Out of scope: other optimizer items (dropped in the stage plan), UI copy.

## Done when

- S2: no full snapshot for single-PID reads at the listed sites (grep evidence); behavior identical (existing tests).
- F10: after an environment job the environment scope is released when empty; a regression test fails on today's code (scope still registered) and passes after; ownership tests green.
- Bad row: a seeded catalog with one row of unknown provider lists all other rows and the runtime starts; the regression test fails on today's code.
