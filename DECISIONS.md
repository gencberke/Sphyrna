# Decisions Registry

Dated user decisions that govern scope, product behavior, visual design, architecture, process, and resource budgets.
- **Rule:** Only `@planner` (the main session) writes this file, and only for decisions `@user` actually made in chat. Never record a guess or a routine task instruction as a decision. When a new decision changes an older one, it gets a new `D-xx` ID naming the decision it amends or supersedes, and the superseded rule moves to [§2 Rejected & Superseded Decisions](#2-rejected--superseded-decisions).
- Product specifications built from these decisions live in [`SPEC.md`](SPEC.md), visual rules in [`design/DESIGN.md`](design/DESIGN.md), and architectural rules in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
